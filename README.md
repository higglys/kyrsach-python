📚 **Python Library Bot — твоя библиотека знаний по Python!** 🐍

Разрабатываю Telegram-бота, который помогает находить полезные материалы для изучения Python в одном месте.

📌 **Что умеет бот?**

📖 **Учебники** — ресурсы для изучения Python с нуля и дальнейшего развития навыков.

📚 **Справочники** — документация по функциям, типам данных и стандартным библиотекам.

🛠 **Методички** — практические руководства по обработке ошибок, тестированию, Git, SQLite и созданию Telegram-ботов.

🔗 Все материалы доступны по ссылкам прямо в Telegram — никаких лишних файлов и сложной навигации!

⚙️ **Технологии проекта:**
- Python
- aiogram 3
- Telegram Bot API
- python-dotenv

🎯 **Цель проекта** — собрать полезные ресурсы для начинающих разработчиков и сделать обучение более удобным.

🚀 Проект постепенно развивается, а впереди ещё много интересных улучшений!
