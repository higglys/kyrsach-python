# Python Library Bot

Telegram-бот с библиотекой учебных материалов по Python. Он помогает находить учебники, справочники и практические руководства, открывая их по ссылкам прямо из Telegram.

## Возможности

- Просмотр библиотеки учебных материалов.
- Три категории: **Учебники**, **Справочники** и **Методички**.
- Inline-кнопки со ссылками на учебные ресурсы.
- Главное меню и навигация по категориям.
- Команды `/start`, `/library`, `/help` и `/cancel`.
- Обработка неизвестных сообщений.

Материалы предоставляются в виде внешних ссылок. Бот не хранит и не отправляет PDF-файлы.

## Технологии

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/en/latest/)
- [python-dotenv](https://pypi.org/project/python-dotenv/)

## Структура проекта

```text
python_library_bot/
├── bot.py
├── token.env
├── .gitignore
└── README.md
```

- `bot.py` — код Telegram-бота.
- `token.env` — токен бота; не публикуйте этот файл в открытом репозитории.
- `.gitignore` — список файлов, которые Git не должен добавлять в репозиторий.

## Требования

- Установленный Python 3.10 или новее.
- Созданный Telegram-бот через [@BotFather](https://t.me/BotFather).
- Подключение к интернету для обращения к Telegram Bot API.

## Установка и запуск

### 1. Скачайте проект

Если проект уже находится у вас на компьютере, откройте его папку в VS Code.

Если проект размещён на GitHub, клонируйте репозиторий:

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd python_library_bot
```

### 2. Создайте виртуальное окружение (рекомендуется)

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Если PowerShell не позволяет активировать окружение, можно использовать терминал Command Prompt:

```bat
.venv\Scripts\activate.bat
```

Linux или macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
python -m pip install -U aiogram python-dotenv
```

### 4. Настройте токен

Создайте файл `token.env` в корневой папке проекта:

```env
BOT_TOKEN=ВСТАВЬТЕ_СЮДА_ТОКЕН_БОТА
```

Замените значение токеном, полученным у BotFather. Не публикуйте токен и не отправляйте его другим людям.

### 5. Запустите бота

```bash
python bot.py
```

После запуска откройте бота в Telegram и отправьте команду `/start`.

Чтобы остановить бота в терминале, нажмите `Ctrl+C`.

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Показать приветствие и главное меню |
| `/library` | Открыть категории материалов |
| `/help` | Показать список команд |
| `/cancel` | Вернуться в главное меню |

## Как пользоваться ботом

1. Отправьте `/start`.
2. Нажмите **Библиотека**.
3. Выберите **Учебники**, **Справочники** или **Методички**.
4. Прочитайте краткие описания и нажмите inline-кнопку нужного ресурса, чтобы открыть сайт.

## Безопасность

Не загружайте `token.env` в GitHub. Добавьте в `.gitignore` как минимум:

```gitignore
token.env
.env
.venv/
__pycache__/
*.py[cod]
```

Если токен случайно попал в публичный репозиторий или был раскрыт, отзовите его через BotFather и создайте новый.

## Развёртывание на сервере

Для работы на сервере установите зависимости и задайте переменную окружения `BOT_TOKEN` в настройках сервиса либо используйте защищённый файл окружения, который не попадает в репозиторий.

Бот использует long polling (`start_polling`), поэтому на хостинге ему нужен постоянно работающий процесс. Учитывайте ограничения бесплатного тарифа: некоторые платформы усыпляют приложения или не разрешают постоянные фоновые процессы.

Не запускайте одновременно несколько экземпляров одного polling-бота с одним токеном — это может вызвать ошибку `TelegramConflictError`.

## Возможные проблемы

- **`Не найден BOT_TOKEN`** — проверьте имя файла `token.env`, имя переменной `BOT_TOKEN` и расположение файла.
- **`TelegramConflictError`** — остановите другие экземпляры бота, использующие тот же токен.
- **Ошибка сети Telegram** — проверьте интернет-соединение и доступность Telegram Bot API с вашего компьютера или сервера.
- **Модули не найдены** — активируйте нужное виртуальное окружение и установите зависимости.
